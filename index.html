Featured Projects

Outlook Calendar Integration

Role: Product Manager Company: BarBooks Australia (Legal SaaS)

The Problem

Barristers and clerks manually updated schedules in both Outlook and BarBooks, causing double bookings, missing appointments, and significant administrative burden. This reduced productivity and increased the risk of costly errors due to data inconsistency.

What I Did

  • Analyzed historical scheduling conflict data and user error logs to quantify the impact of manual entry errors and prioritize sync logic rules.
  • Conducted user interviews to map scheduling workflows and pain points.
  • Defined functional requirements, sync logic, and acceptance criteria in PRDs.
  • Led technical discovery to select Microsoft Graph API (OAuth 2.0) for secure, real-time sync.
  • Coordinated engineering delivery, testing (UAT), and conflict resolution logic design.

Outcome

60% Reduction in Manual Scheduling

Eliminated duplicate entry and saving hours weekly.

2x Increase in Calendar Feature Adoption

Driving daily engagement through seamless integration.

Diary Redesign: UI Revamp for Clerk View

Role: Product Manager Company: BarBooks Australia (Legal SaaS)

The Problem

The legacy Clerk Diary View was inefficient, using excessive screen space and preventing clerks from viewing necessary scheduling and user information at a glance. This poor UX impacted usability and required constant scrolling/switching.

What I Did

  • Reviewed click-stream data and user heatmaps to identify bottlenecks in the multi-tab navigation and guide the design of the unified view.
  • Conducted user interviews and design sessions with clerks to map workflow needs.
  • Defined requirements for new compact filters and unified diary view.
  • Led discovery sessions on sorting rules and coordinated engineering delivery through UAT.
  • Prepared release notes and updated user guides to ensure that users adapt quickly to the UX change.

Outcome

50% Reduction in User Clicks

Streamlined scheduling workflow, cutting clicks from 8 to 4 for common tasks.

Immediate Adoption by 100% of Clerk Users

Unified view eliminated need to switch between screens, improving daily efficiency.
