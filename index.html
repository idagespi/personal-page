Case Studies: Delivering Scalable Outcomes

Outlook Calendar Integration (Jul 2023 – Feb 2024)

Role: Product Manager Company: BarBooks Australia (Legal SaaS)

The Problem

Barristers and clerks manually updated schedules in both Outlook and BarBooks, causing **double bookings, missing appointments, and significant administrative burden**. This reduced productivity and increased the risk of costly errors due to data inconsistency.

What I Did

  • Defined precise sync logic (one-way/two-way) and managed data mapping between platforms.
  • Led technical discovery, choosing **Microsoft Graph API (OAuth 2.0)** for secure, real-time synchronization.
  • Designed the conflict resolution logic and implemented a sync queuing system to handle API rate limits.
  • Coordinated phased rollout, user training, and UAT to identify and resolve edge cases (e.g., deleted bookings).

Outcome

Goal Achieved: Seamless Sync

Eliminated the need for duplicate entry, ensuring **real-time visibility** and **reduced scheduling conflicts** across the user base.

Improved Productivity

Significantly reduced the administrative burden on clerks and barristers, allowing them to focus on legal work.

Diary Redesign: UI Revamp for Clerk View

Role: Product Manager Company: BarBooks Australia (Legal SaaS)

The Problem

The legacy Clerk Diary View was inefficient, using excessive screen space and preventing clerks from viewing necessary scheduling and user information at a glance. This poor UX impacted usability and required constant scrolling/switching.

HubSpot linked tickets included concerns over layout, filter functionality, and visibility (e.g., #3 email re TALAW diary, Diary suggestions!).

What I Did (UI/UX & Hierarchy)

  • Led UI/UX redesign to maximize screen space (full row height) and consolidate user filters into a compact, space-saving UI.
  • Unified the Diaries table to list all users (Barristers + Non-Barristers) in one view, removing cluttering sub-tabs.
  • Implemented advanced, compact filter components with search bars, clear CTAs, and optimized selection display rules (number vs. name).
  • Defined new sorting behaviors to ensure Barristers maintain priority while still allowing detailed filtering (e.g., Sort by Last Name).
  • Redesigned the collateral elements (Booking Button, Toolbar, Settings, Export) for better alignment and modern aesthetics.

Outcome

Reduced Clicks & Friction

Diary usage flow for clerks was optimized, **reducing the number of clicks required by half** for common scheduling tasks.

Positive User Feedback

Received general positive customer feedback confirming enhanced usability and efficiency across the unified view.
